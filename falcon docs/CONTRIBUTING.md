# Contributing to FALCON

## Before contributing
- Read `README.md` and `DEV_RULES.md`.
- Identify the package boundary for your change.
- Open or update an issue for non-trivial work.

## Development workflow
1. Create a focused branch.
2. Install dependencies with pnpm.
3. Implement a small change.
4. Add tests and fixtures.
5. Run lint, typecheck and tests.
6. Update docs and examples.
7. Open a PR with behavior, rationale, tests and limitations.

## Pull request checklist
- [ ] Scope is focused.
- [ ] Architecture boundaries are preserved.
- [ ] Tests cover expected and failure cases.
- [ ] No secrets or generated artifacts.
- [ ] No unapproved dependencies.
- [ ] Documentation reflects behavior.
- [ ] Claims are evidence-based.
